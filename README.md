\# DevOps Python Project



Учебный проект для выполнения СРСП по дисциплине «Прикладные аспекты DevOps».



\## Описание



Проект представляет собой простой калькулятор на Python.



Приложение содержит функции:



\- сложение;

\- вычитание;

\- умножение;

\- деление.



\## Тестирование



Для тестирования используется pytest.



Проект содержит четыре unit-теста.



\## CI/CD



Для автоматизации используется GitHub Actions.



Pipeline выполняет следующие этапы:



1\. Install — установка зависимостей;

2\. Build — проверка и компиляция Python-кода;

3\. Test — запуск unit-тестов.



Pipeline автоматически запускается после каждого push в репозиторий.
